# ibond — K-Bond 라이브 호가창 (화면)

장외 채권 메신저 호가를 접어 만든 호가창의 **화면 한 장**이다.

## 이게 무엇이고 데이터는 어디 있나

책(호가·체결·딜러)은 이 리포에 없다. **원장·파서·민평은 전부 로컬 백엔드**에 있고,
이 HTML 은 그 백엔드를 브라우저에서 직접 부른다. Vercel 은 HTML 을 배달할 뿐,
데이터를 중계하지 않는다.

    브라우저 ──HTML── Vercel (이 리포)
        └──JSON/SSE──> Tailscale Funnel ──> 로컬 PC 의 kbond_live.py

그래서 **백엔드 PC 가 켜져 있을 때만 화면에 값이 선다.** 꺼져 있으면 연결 실패로 보인다.

## 주소와 토큰

첫 진입에서 «서버 주소»와 «토큰»을 묻고 그 브라우저에만(localStorage) 저장한다.
**리포에도 번들에도 주소·토큰이 들어가지 않는다** — Vercel 에 넣을 환경변수도 없다.
토큰이 틀리면 백엔드가 401 을 주고 화면은 설정으로 되돌아간다.

## 화면을 고칠 때

`public/index.html` 은 백엔드 폴더 `kbond_live.html` 의 **복사본**이다. 둘이 갈라지므로
백엔드 쪽을 고쳤으면 복사해 온다. (자동화는 아직 없다.)

    copy ..\kbond\kbond_live.html public\index.html

## 딜러 이름

백엔드가 딜러 이름과 전화번호를 라벨(`H01-2`)로 가려서 보낸다. 이 화면은 받은 것을
그릴 뿐이고, 가림을 끄는 스위치는 백엔드에 있다.
