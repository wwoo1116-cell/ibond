**과녁 = 민평3사가 맞다.** `kbond.marketvalue` 의 `3사평균` 은 나이스·키스·한국자산 셋이고

## 4. 13시가 안 되는 이유 — 원리다

오차를 날짜 공통분과 종목 고유분으로 쪼개면 (13:00):

```
날짜별 평균오차의 sd    1.93bp   ← 그날 통째로 밀리는 폭
날짜 안 종목별 sd       0.89bp
분산 중 «날짜 공통» 몫    82%      (제일 활발한 칸만 봐도 89%)
```

13시 이후 커브가 실제로 더 움직이는 폭이 **중앙 1.09bp · p80 2.30 · p90 3.11**(540일).
13시에 마감 커브를 좁게 말하라는 건 **오후 두 시간 반의 시장을 미리 알라는 요구**다.

증거 둘.

- 13:00 에 「오늘 마감 커브」만 안다고 치면 오차가 1.10 → **0.50**(p80 2.45 → 1.15)로 준다.
- 13:00 에 제일 활발한 칸(양면·9건+)에서 **자기 호가만 1.15 / 커브만 1.15 / 섞음 1.13** —
  추정기를 뭘 쓰든 같다. 커브는 오차의 원인이 아니라 호가 없는 종목을 덮는 도구였다.

조용한 날만 골라도 안 좁아진다(13시까지 커브이동 최소 사분위 135일에서도 p80 2.10bp).

## 7. 바닥 — 학습으로 못 없애는 몫

`kbond.marketvalue` 의 4사 개별 민평으로 직접 쟀다(국고 39,275 종목일·499일).

- 4사 범위 중앙 **0.50bp** · p90 2.00 · 0.5bp 이내 59%
- 개별사 편차의 **자기상관 0.71** → 대부분 「저 회사는 원래 좀 높다」는 지속적 차이 = 예측 가능
- 예측 불가능한 건 편차의 **하루 변화**, 개별사 sd **0.307bp** → 평균값의 몫 약 **0.15bp**

사다리:

```
아무것도 안 함        2.00bp
13:00               1.10
15:30               0.63
16:00 (RF)          0.29
커브 오라클           0.26
평가사 재량 바닥       ~0.15
```

**크레딧 경고: 4사 범위가 중앙 2.70bp · p90 8.30bp 로 국고의 다섯 배다.**
크레딧에서 「민평 −3」이 어느 평가사 민평이냐에 따라 2~3bp 달라진다. 크레딧으로 옮기려면
**「어느 민평이 과녁인가」부터 정해야 한다**(데스크 관행 문제, 오너 판단).

## 8. ★내가 낸 오류 셋 — 전부 결론을 움직였다

세 번 다 고친 뒤 결론이 더 선명해졌다. 크레딧 판으로 옮길 때 그대로 적용할 것.

1. **상대가 자기 답을 보고 있었다.** 비교 상대 「구간규칙」이 중앙값에 자기 자신을 포함
   (커브 쪽은 leave-one-out 인데). 평균 0.21~0.25bp 어치. → LOO 로 고침(`fixrule.py`).
   **레인 규율 「귀속 규칙과 설명 변수가 축을 공유하면 그건 검정이 아니다」의 재발이다.**
2. **검정 종류가 틀렸다.** 「커브」와 「커브+ML」은 포함관계(nested)라 단순 짝 t 를 쓰면 안 된다.
   Clark-West(포함) + DM/HLN(비포함)으로 갈라 다시 쟀다. 보고했던 t 2.36 → **t 4.70**.
   원래 주장이 과장이 아니라 **과소**였다. HLN 보정 자체는 T>100 이라 영향 없음(계수 0.995).
3. **결측 10.7%를 조용히 버리고 있었다.** `train3.build` 가 커브 적합 실패 행을 drop.
   버려진 행은 양면비율 35%(전체 59%)·|y| 중앙 2.20bp(전체 1.90) — **얇고 많이 움직인 종목이
   골라서 빠졌다.** → 규칙→0 순으로 되돌리게 고침(`zoo.prep`). 보고치가 0.70 → 0.72 정도로 조정.

부수로 확인한 것: **피처 결측은 문제없었다.** 비드 없음 28.5%·오퍼 없음 12.0%·스프레드 40.5%·
`res_prev` 14.7% 인데 `HistGradientBoosting` 은 결측을 자체 처리한다. RF/ET/GB 는 못 먹어서
중앙값 대치 + 「결측이었다」 표시열을 준다. 선형 모형도 같다.
