## §1 못 박힌 사실 넷

1. **민평 확정 = 16:00.** 두 갈래 독립 확인. ① 16:15 이후 호가는 추정을 못 바꾼다
   (15:45 0.65 → 16:00 0.40 → 16:15 0.38 → 17:00·18:00 0.40, 같은 종목일 고정).
   ② 호가가 16:00 정각에 기준선의 **24배**로 몰린다(15:30~15:44 는 오히려 0.58배로 죽는다).
   외부 근거와 일치 — 「민평금리를 확정해야 하는 오후 4시를 불과 10여분 앞두고…」(이투데이).
2. **과녁 = 민평3사 = 나이스·키스·한국자산.** `국고통_민평` 이 곧 그것이다(중앙 0.000bp·77.5% 일치).
   바꿀 것 없다. `marketvalue.bonddate = D` ↔ `국고통_민평.일자 = D−1` 규약만 주의.
3. **13시는 원리상 막혔다.** 오차 분산의 **82%**(활발한 칸만 보면 89%)가 「오후에 커브가
   어디로 갈지 모른다」 하나다. 13시 이후 커브가 실제로 중앙 1.09bp·p90 3.11bp 더 움직인다.
4. **바닥은 ~0.15bp.** 4사 편차의 «하루 변화» sd 0.307bp(개별사), 평균값은 그 절반.
   사다리: 아무것도 안 함 2.00 → 13:00 1.10 → 15:30 0.63 → **16:00 0.29** → 커브 오라클 0.26 → 바닥 0.15.

## §2 죽은 것 넷 — 되살리지 말 것

- **13시 수준 추정**([OWNER] 접음). ACI 구간이 80%에 ±2.85bp = 하루 이동폭보다 넓다.
- **[B] 민평 지연 가설** — R² 0.0003, 커브 통제하면 부호가 뒤집힌다. 민평은 늦게 안 따라온다.
- **블렌드(0.5 자기호가 + 0.5 커브)** — CPCV 45조각 중 규칙을 이긴 건 22%/11%뿐.
- **AutoML** — FLAML 180초가 기본값 RandomForest 를 못 이긴다(0.34 대 0.29).

## §3 규율 — 오늘 내가 세 번 어겼다

1. **비교 상대에게 자기 답을 보여 주지 말 것.** 구간규칙이 중앙값에 자기를 포함하고 있었다
   (0.21~0.25bp 어치). 레인 규율 「귀속 규칙과 설명 변수가 축을 공유하면 그건 검정이 아니다」의 재발.
2. **포함관계에는 짝 t 를 쓰지 말 것.** 「커브」와 「커브+ML」은 nested → Clark-West.
   비포함은 DM+HLN. 날짜 클러스터 + Newey-West 는 둘 다. 고치니 t 2.36 → **4.70**(과장이 아니라 과소였다).
3. **조용히 버리지 말 것.** 커브 적합 실패 10.7%를 drop 하고 있었고, 빠진 것이
   **얇고 많이 움직인 종목**이었다. 지금은 규칙→0 으로 되돌린다(`zoo.prep`).

추가: **컷오프를 먼저 정하고 모형을 고를 것.** 같은 모형이 13:00 에선 무의미하고
16:00 에선 36% 를 번다. 모형 비교표를 컷오프 없이 읽으면 틀린 결론이 난다.
