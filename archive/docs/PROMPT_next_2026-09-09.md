## 10. 데인 것 — 09-09 추가분

1. **재파싱 중에 사전·코드를 고치면 안 된다.** 워커가 ProcessPoolExecutor 로 떠서
   중간에 새 코드를 집는다. 오늘 21분을 그렇게 버렸다.
2. **`.map()` 의 미매칭은 `None` 이 아니라 `NaN`.** `str` dtype 에서는
   `.where(...,None)` 으로도 안 돌아온다 — `astype(object)` 로 내린 뒤 바꾼다.
3. **여는 괄호만 뜯는 정규식은 조용히 이름을 죽인다.** `[)]?` 를 선택으로 두려면
   내용에 «반드시 있어야 할 글자» 를 요구해야 한다(「(주)에스파워」 -> 「주)에스파워」).
4. **꼬리 문법의 검사 순서가 뜻을 바꾼다.** 홑글자 「사」(사회적채권)를 STRUCTURE 에
   넣으면 「사자」가 「사」+「자」로 쪼개진다. 여러 글자 토큰(DROP)을 먼저 본다.
5. **정규식 매치 구간을 «본문» 으로 쓰면 안 된다.** 매치는 «자를 자리» 로만 쓴다.
6. **파일을 바이너리로 읽고 텍스트로 쓰면 `\r\n` 이 `\r\r\n` 이 된다.**
   `kbond_legs.py` 300줄이 그렇게 돼 diff 가 570줄로 부풀었다(실제 편집 48줄).
7. **소스에 거래상대 실명·전화가 45건 쌓여 있었다.** 밖으로 올리기 전에
   `python scrub_desk_names.py --dry` 로 훑을 것. ⚠데스크명 전역 치환 금지 —
   「한화」·「삼성」은 발행체 이름이기도 하다.
8. **`git rm --cached` 는 이력을 안 지운다.** 공개 리포에 올릴 거면 커밋을 다시 쌓는다.
9. **`Stop-ScheduledTask` 는 자식 프로세스를 안 죽인다.** 포트가 안 놓이면 PID 를
   직접 죽여야 한다. ⚠`Get-CimInstance -Filter "CommandLine LIKE '%port 8301%'"` 는
   **자기 자신도 잡는다** — 유령 프로세스로 착각했다.
